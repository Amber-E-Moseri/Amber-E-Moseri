Hey, I'm Amber 👋

I build solutions to real problems. I love creating systems that actually work — ones that fit how people operate, not the reverse. I'm obsessed with data, automation, and eliminating redundant work through systems thinking.

I started with process automation in Google Apps Script. Now I'm building full platforms in production, owning the technical and product decisions end-to-end.

🧠 How I Think

I map before I build.

I start by understanding the process as it exists:

People → Steps → Dependencies → Data → Bottlenecks → Sources of Truth

Once I can see the system clearly, I can decide what should be simplified, automated, or rebuilt.

What drives me is a strive for excellence and continuous improvement. Getting something to work is the beginning, not the finish line. I keep asking:

Can this be simpler? More reliable? More useful? Is there redundant work we can eliminate? Is the architecture still right as the system grows?

That mindset is why my projects evolve. A reporting automation became Nexus's reporting layer. Flock's relationship workflows were folded into Nexus. Each system teaches me something that improves the next version.

Map → Identify → Build → Measure → Improve

RAF / Nomi — Personal Finance Platform

Multi-tenant finance · PostgreSQL security · Deterministic financial domain

Repository link will be added when the public RAF/Nomi repository URL is confirmed.

A personal finance and stewardship platform built around a deterministic Revenue Allocation Formula.

Most finance tools focus on explaining where money went. RAF starts one step earlier:

Where should this money go?

Architecture

Multi-workspace / household tenancy

PostgreSQL Row-Level Security

Least-privilege runtime database roles

Financial accounts and reconciliation

Bank-statement imports and duplicate detection

Transaction categorization and attribution

Goal and debt tracking

Debt payment-pace and balance-trajectory modeling

Deterministic 30/60/90-day cash-flow forecasting

Monthly review lifecycle with immutable snapshots

Audit trails and production monitoring

AI assistant with strict financial-authority boundaries

Architecture principle

AI can explain financial state. It doesn't define financial truth.

RAF is where I'm going deepest on domain modeling, multi-tenancy, financial correctness, authorization, and backend architecture.
